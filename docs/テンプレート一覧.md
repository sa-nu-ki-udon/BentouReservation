## テンプレートの共通構造

全てのテンプレートは以下の構造を持ちます：

```html
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org"
      xmlns:layout="http://www.ultraq.net.nz/thymeleaf/layout"
      layout:decorate="~{layout/default}">
<head>
    <title>ページタイトル</title>
</head>
<body>
    <main layout:fragment="content">
        <!-- ページ固有のコンテンツ -->
    </main>

    <th:block layout:fragment="scripts">
        <!-- ページ固有のJavaScript -->
    </th:block>
</body>
</html>
```

## 共通コンポーネント

### 検索フォーム
```html
<form th:action="@{/path}" method="get" class="input-group">
    <input type="text" name="searchParam" class="form-control" placeholder="検索">
    <button type="submit" class="btn btn-outline-secondary">
        <i class="bi bi-search"></i> 検索
    </button>
</form>
```

### テーブル
```html
<div class="table-responsive">
    <table class="table table-hover">
        <thead>
            <tr>
                <th>列名</th>
            </tr>
        </thead>
        <tbody>
            <tr th:each="item : ${items}">
                <td th:text="${item.property}"></td>
            </tr>
        </tbody>
    </table>
</div>
```

### フォーム
```html
<form th:action="@{/path}" th:object="${formObject}" method="post">
    <div class="mb-3">
        <label class="form-label form-required">項目名</label>
        <input type="text" class="form-control" th:field="*{fieldName}">
        <div class="field-error" th:if="${#fields.hasErrors('fieldName')}"
             th:errors="*{fieldName}"></div>
    </div>
    <button type="submit" class="btn btn-primary">保存</button>
</form>
```

### カレンダーグリッド
```html
<div class="row">
    <div class="col" th:each="day : ${calendarDays}">
        <div class="calendar-day"
             th:classappend="${day.isHoliday ? 'holiday' : ''}"
             th:classappend="${day.isToday ? 'today' : ''}"
             th:classappend="${day.hasOrder ? 'has-order' : ''}">
            <div th:text="${day.date}"></div>
            <div th:text="${day.menuSetName}"></div>
        </div>
    </div>
</div>
```

### 月次ナビゲーション
```html
<div class="month-navigation">
```

## スタイルクラス

### 状態表示
- `.status-active` - 有効状態（緑）
- `.status-deleted` - 削除済み（グレー）
- `.status-holiday` - 休日（赤）
- `.status-orderable` - 注文可能（緑）
- `.status-not-orderable` - 注文不可（グレー）

### カレンダー
- `.calendar-day` - カレンダーの日付セル
- `.calendar-day.holiday` - 休日
- `.calendar-day.today` - 今日
- `.calendar-day.has-order` - 注文済み
- `.calendar-day.orderable` - 注文可能
- `.calendar-day.not-orderable` - 注文不可

### 印刷
- `.no-print` - 印刷時に非表示

## 次のステップ

残りのテンプレートを作成する際は、以下の優先順位で進めます：

1. **注文系** - 注文カレンダー、注文入力/変更（コア機能）
2. **カレンダー設定** - カレンダー表示、設定フォーム（コア機能）
3. **日次集計** - 集計表示、印刷画面（業務に必須）
4. **月次集計** - 社員別/業者別集計
5. **マスタ管理** - 詳細/新規/編集画面（CRUD操作）

各テンプレートは、業者一覧テンプレートと同様の構造で作成します。
